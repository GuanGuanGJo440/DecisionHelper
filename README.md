# Decision Wheel (iOS App)

A SwiftUI-based decision-making app that helps users choose options 
by spinning a wheel. Users can organize decisions into folders and 
save frequently used choices.

## Features
- 🎯 Create decision sets with multiple options
- 📂 Organize decisions using folders
- ⭐ Favorite decision lists
- 🎡 Spin wheel animation for random selection
- 💾 Local data persistence

## Tech Stack
- Swift
- SwiftUI
- MVVM architecture
- Codable for local storage
